# Security Policy

## Vulnerability Disclosure

Security is a primary requirement for this repository. If you identify a potential security issue or vulnerability, please do not file a public issue.

Please report the finding privately through GitHub:
1. Go to the **Security** tab of this repository on GitHub.
2. Select **Report a vulnerability** to submit a confidential report.

If this route is not accessible, you may reach out directly to the maintainer via their GitHub profile (@baerozgaarmard).

## Scope

Security updates are actively maintained on the `main` branch.
